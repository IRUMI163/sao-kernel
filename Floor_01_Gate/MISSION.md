## 🎴 画面出力の基本パターン（Pattern Example）

この第1層で君がマスターすべき構文の「型」はこれだ。迷ったら常にここに戻りたまえ。

```c
/* 基本パターン：文字だけを画面に出す */
printf("表示したい文章\n");

/* 応用パターン：文章の中にある穴（%s や %d）に変数をスポッとはめ込む */
printf("名前: %s, レベル: %d\n", player_name, level);
```

## 🔍 【まずはここから】いま画面に開いている `main.c` の1行ずつ完全解体新書

エディタで `Floor_01_Gate/main.c` を開くと、最初からいくつかの呪文が書かれているはずだ。
プログラミング初心者が抱く「そもそも最初から書いてあるこの英単語たちは何なんだ？」という疑問を、上から1行ずつすべて解き明かそう。

```c
 1: #include <stdio.h>
 2: #include "../shared/sao_ui.h"
 3: 
 4: int main(void) {
 5:     const char *player_name = "KIRITO";
 6:     int level = 1;
 7:     int hp_current = 250;
 8:     int hp_max = 250;
 9:     double storage_used = 42.5;
10: 
11:     SAO_PRINT_HEADER("STATUS WINDOW");
...
25:     SAO_PRINT_FOOTER();
26: 
27:     return 1;
28: }
```

### 1行目: `#include <stdio.h>`
- **読み方**: インクルード・スタンダード・アイ・オー・ドット・エイチ
- **意味**: 画面に文字を出す道具（`printf` など）が入った標準道具箱 `<stdio.h>` を取り出す呪文。C言語は最初は何もない空っぽの状態なので、冒頭で道具箱を読み込む必要がある。

### 2行目: `#include "../shared/sao_ui.h"`
- **読み方**: インクルード・エス・エー・オー・ユー・アイ・ドット・エイチ
- **意味**: アインクラッドのシステムウィンドウ枠（`===` のカッコいい枠線）を描画するための特製パーツ箱を読み込んでいる。

### 4行目: `int main(void) {`
- **読み方**: イント・メイン・ボイド
- **意味**: **「ここからプログラムがスタートするぞ！」という一番最初の玄関口**。
  - `main`: 「主役の処理」という意味。
  - `int`: 最後に「終了ステータス（数字）」をOSに報告するという約束。
  - `void`: 外から特別なデータを受け取らないという意味。
  - `{`: ここから処理の部屋（ブロック）が始まる合図。

### 5〜9行目: 変数（ロッカー）の準備
- `const char *player_name = "KIRITO";`
  - 文字列（文字の並び）を入れる箱。`"KIRITO"` という名前を記憶させている。
- `int level = 1;` / `int hp_current = 250;`
  - 整数を入れる箱（`int`）。レベルやHP数値を記憶させている。
- `double storage_used = 42.5;`
  - 小数を入れられる高精度な箱（`double`）。ストレージ使用率 `42.5` を記憶させている。

### 11行目 & 25行目: `SAO_PRINT_HEADER(...)` / `SAO_PRINT_FOOTER();`
- アインクラッドの青いウィンドウ枠線（`====================`）を上下に自動で描画してくれるシステムマクロだ。君はこの2行の「間」にコードを書けばいい。

### 19〜23行目: `(void)player_name;` って何！？
- **正体**: これは**「未完成コード用の一時的なお守り（警告消し）」**だ！
- C言語のコンパイラは非常に几帳面で、「せっかく用意した変数を使っていないぞ！」とエラー（警告）を出して止めてしまう。
- そこで「いまは未完成だから使ってないけど怒らないでね」とコンパイラを言いくるめるために書いてある。
- **自分で `printf` を書いてその変数を使うようになったら、この `(void)...;` の行は完全に消してしまって構わないぞ！**

### 27行目: `return 1;`
- **意味**: OSに対して「プログラムが異常終了（失敗）しました」と伝える合図。
- スケルトン状態ではあえて失敗するように `1` にしてある。**完成したら `return 0;`（成功の合図）に書き換えるのだ**。

## 📖 茅場晶彦のカタカナ英語ルビ辞典（Ruby Words）

現場のエンジニアが当たり前のように口にする単語の意味を押さえておこう。

| 単語 | カタカナ読み | 意味・役割 |
| :--- | :--- | :--- |
| **`printf`** | プリント・エフ | Print Formatの略。文字や変数の値を画面（コンソール）に出力する命令。 |
| **`include`** | インクルード | 「含める」という意味。外部のヘッダーファイル（道具箱）を読み込む言葉。 |
| **`string`** | ストリング | ダブルクォーテーション `""` で囲まれた「文字列データ」のこと。 |
| **`int`** | イント | Integer（整数）の略。-1, 0, 100 などの端数のない数値を扱う型。 |
| **`double`** | ダブル | 実数（小数）を扱える型。倍精度（Double Precision）が名前の由来。 |
| **`return`** | リターン | 関数の処理を終え、呼び出し元（OS）に結果の数値を返す命令。 |
| **`\n`** | カイギョウ（エスケープシーケンス） | 改行（New Line）の命令。画面表示で次の行に移るための合図。 |

## 💡 【これが実際の現場でどう使えるか】

今回学ぶ `printf` とフォーマット指定子は、単なる画面表示ではありません。
プロの現場でプログラムがクラッシュした時、**「いまメモリの中の変数はどんな値になっているのか？」「何行目まで正しく動いたのか？」を調査する『探偵の虫眼鏡（デバッグログ）』** として、世界中のエンジニアが24時間365日使い続ける超必須スキルです。

## 🧩 穴埋めパズル（フォーマット指定子）の仕組み

文章の中に `%` で穴を開け、カンマ `,` の後ろに変数を並べると、左から順にスポッとはまります。

```text
printf("PLAYER : %s\n", player_name);
                  ▲           │
                  │           │
                  └──── 代入 ─┘
```

### 穴（指定子）の種類一覧

1. **`%s`（文字列）**: 文字の並びを埋め込む。
   ```c
   printf("PLAYER : %s\n", player_name);
   // 画面出力 ➔ PLAYER : KIRITO
   ```
2. **`%04d`（4桁ゼロ埋め整数）**:
   `%d` は通常の整数だが、`04` を挟むと「全体で4文字分の幅を取り、足りない左側を `0` で埋める」という意味になる！
   ```c
   printf("LEVEL  : %04d\n", level);
   // 画面出力 ➔ LEVEL  : 0001
   ```
3. **`%.1f%%`（小数第1位 ＋ パーセント記号）**:
   `%.1f` で小数を1位までに制限し、`%` という文字そのものを画面に出すために `%%` と2つ重ねる。
   ```c
   printf("STORAGE: %.1f%% USED\n", storage_used);
   // 画面出力 ➔ STORAGE: 42.5% USED
   ```

### 穴が2つある時はどうするの？
カンマの後ろに、穴の数だけ順番に変数を並べるだけだ：
```c
printf("HP     : %04d / %04d\n", hp_current, hp_max);
                   ▲      ▲            │        │
                   │      └────────────┼────────┘
                   └───────────────────┘
// 画面出力 ➔ HP     : 0250 / 0250
```
