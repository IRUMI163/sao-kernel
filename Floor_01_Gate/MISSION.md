## 1. この階層で学ぶC言語の核心

### ① `#include` と `main` 関数（すべての始まり）
C言語のプログラムは、必ず `main` という名前の関数から実行が開始されます。画面に文字を表示するための標準道具箱 `<stdio.h>`（Standard Input/Output Header）を冒頭で読み込みます。

```c
#include <stdio.h>

int main(void) {
    printf("Link Start!\n");
    return 0; // OSに「正常終了（エラーなし）」を伝える数値
}
```

### ② データ型とフォーマット指定子（型にはめる美学）
C言語では、扱うデータの種類（型）を明確に宣言しなければなりません。また、`printf` で変数を表示する際は「どんな形式で埋め込むか」を指定する**フォーマット指定子**を使います。

| データ型 | 意味 | `printf` 指定子 | 応用テクニック（桁揃え・小数制御） |
| :--- | :--- | :--- | :--- |
| `const char *` | 文字列 | `%s` | `"%s"` で文字列をそのまま埋め込む |
| `int` | 整数 | `%d` | `"%04d"` と書くと `4` 桁のゼロ埋め（例: `0001`）になる |
| `double` | 倍精度実数（小数） | `%f` | `"%.1f"` と書くと小数点以下 `1` 桁まで表示（例: `42.5`） |

> 💡 **注意**: `printf` の中で `%` という記号そのものを画面に表示したい場合は、`%%` と2つ続けて記述します（例: `"%.1f%%\n"` ➔ `42.5%`）。

## 2. 現場で飛び交う業界用語辞典

- **CLI（Command Line Interface / 黒い画面）**:
  文字（コマンド）だけでコンピュータに命令を下す画面のこと。GUI（マウス操作）よりも圧倒的に高速で、自動化が容易なためプロの現場では必須となる。
- **コンパイル（Compile）とバイナリ（Binary）**:
  人間が書いたC言語のソースコード（`.c`）は、そのままではCPUには理解できない。コンパイラ（`gcc` や `clang`）を使って、CPUが直接実行できる「0と1の機械語ファイル（バイナリ）」に翻訳する作業をコンパイルと呼ぶ。
- **標準出力（stdout）と終了ステータス（Exit Status）**:
  プログラムが画面に出す通常の文字出力を `stdout` と呼ぶ。そして `main` 関数の最後にある `return 0;` は、プログラム終了時にOSへ返す「終了コード（0＝成功、0以外＝異常終了）」である。
