## 1. この階層で学ぶC言語の核心（ゼロからの超入門）

### ① `#include` と `main` 関数（すべての始まり）
C言語のプログラムは、どんなに巨大なシステムであっても必ず **`main` という名前の関数** から1行ずつ順番に実行されます。

画面に文字を表示するためには、C言語に最初から備わっている道具箱 `<stdio.h>`（Standard Input/Output Header）を冒頭で読み込む必要があります。

```c
#include <stdio.h> // 画面表示の道具（printfなど）を使えるようにするおまじない

int main(void) {
    printf("Link Start!\n");
    return 0; // OSに「正常終了（エラーなし）」を伝える合言葉
}
```

- **`return 0;` の意味**:
  プログラムが正常に最後まで動き切ったことをOS（WindowsやMac）に伝える終了コードです。`0` は「成功」、`0` 以外（`1` など）は「異常終了（エラー）」を意味します。

---

### ② 画面出力の王様：`printf`（プリント・エフ）の解体新書
画面に文字を表示するには `printf` 関数を使います。`f` は **Format（書式）** の略です。

単に決まった文字を表示するだけなら簡単です：
```c
printf("こんにちは\n");
```

しかし、プログラミングでは **「変数（データ）の中身を文章の中に埋め込んで表示したい」** という場面が99%を占めます。そこで登場するのが **「穴埋めパズル（フォーマット指定子）」** です！

#### 穴埋めパズルの図解イメージ
`printf` は、**「ダブルクォーテーション `""` の中に `%` の穴を開けておき、カンマ `,` の後ろに渡した変数を左から順番にスポッとはめ込む」** というルールで動きます。

```text
printf("PLAYER : %s\n", player_name);
                  ▲           │
                  │           │
                  └──── 代入 ─┘
```

1. 文章の中に `%s` という「文字列が入る専用の穴」を開けておく。
2. カンマ `,` の後ろに `player_name` という変数を渡す。
3. 実行されると `%s` が `"KIRITO"` という文字に置き換わり、画面には `PLAYER : KIRITO` と表示されます。

---

### ③ なぜ末尾に `\n` が必要なのか？（エスケープシーケンス）
`\n`（バックスラッシュ＋n、環境によっては `¥n`）は、**「改行（New Line）」** を表す特殊な記号です。

C言語の `printf` は、**自分で明示的に改行を指示しない限り、絶対に改行してくれません**。
もし `\n` を書き忘れるとどうなるでしょうか？

```c
// 悪い例（\n を忘れた場合）
printf("PLAYER : %s", player_name);
printf("LEVEL  : %04d", level);

// 画面の出力結果（横一列に繋がって大惨事に！）
PLAYER : KIRITOLEVEL  : 0001
```

行の終わりには必ず `\n` を入れる、と体に叩き込んでおきましょう。

---

### ④ データ型とフォーマット指定子（穴の形を合わせる）
C言語は型（データの種類）に非常に厳格な言語です。
「どんなデータを入れるか」によって、開ける穴（フォーマット指定子）の形を変えなければなりません。丸い穴に四角いブロックは入らないのと同じです。

| データ型 | 意味 | 指定子 | 具体的コード例 | 画面への出力結果 |
| :--- | :--- | :---: | :--- | :--- |
| `const char *` | 文字列 | **`%s`** | `printf("名前: %s\n", player_name);` | `名前: KIRITO` |
| `int` | 整数 | **`%d`** | `printf("Lv: %d\n", level);` | `Lv: 1` |
| `int` (桁揃え) | 4桁ゼロ埋め整数 | **`%04d`** | `printf("Lv: %04d\n", level);` | `Lv: 0001` |
| `double` | 小数 | **`%f`** | `printf("容量: %f\n", storage_used);` | `容量: 42.500000` |
| `double` (小数制御) | 小数第1位まで | **`%.1f`** | `printf("容量: %.1f\n", storage_used);` | `容量: 42.5` |

#### プロの技：桁揃え `%04d` と 小数点制御 `%.1f`
- **`%04d`**:
  「全体で4文字分の幅を取り、足りない左側の桁を `0` で埋めろ」という命令です。`1` は `0001` に、`250` は `0250` になります。ゲームのHP表示やステータス画面で必須の技術です。
- **`%.1f`**:
  小数は放っておくと `42.500000` のように後ろに不要な `0` がたくさん表示されてしまいます。`.1` と指定することで「小数点以下は1桁だけ表示せよ」と指定できます。
- **`%%`（パーセント自体の表示）**:
  `%` は穴埋めの合図として予約されているため、画面に `%` という文字そのものを出したいときは **`%%` と2つ続けて書く** ルールになっています（例: `%.1f%%` ➔ `42.5%`）。

#### 穴が2つある場合はどう書くの？
カンマの後ろに、穴の数だけ順番に変数を並べます：
```c
// %04d が2つあるので、後ろにも変数を2つ渡す
printf("HP     : %04d / %04d\n", hp_current, hp_max);
                   ▲      ▲            │        │
                   │      └────────────┼────────┘
                   └───────────────────┘
```

---

### ⑤ `main.c` にある謎の行 `(void)player_name;` の正体は？
初期状態の `main.c` を開くと、以下のような謎の記述があります：

```c
(void)player_name;
(void)level;
```

**「これ何！？ 消していいの？ ここに何か書くの？」** と驚くかもしれません。

実はこれ、**「未完成コード用の一時的なお守り（警告消し）」** です。
C言語のコンパイラは非常に優秀で、用意された変数を使わずに放置すると「変数を宣言したのに一度も使っていませんよ！」とエラー（警告）を出してビルドを止めてしまいます。
`(void)変数名;` と書くことで、「まだ使っていないけど無視してね」とコンパイラを納得させていたのです。

したがって、**自分で `printf` を書いてその変数を使うようになったら、この `(void)...;` の行は削除してしまって構いません！**（残していても害はありませんが、消した方が綺麗です）。

## 2. 現場で飛び交う業界用語辞典

- **CLI（Command Line Interface / 黒い画面）**:
  マウスを使わず、キーボードで文字（コマンド）を打ち込んでコンピュータを操作する画面のこと。GUI（一般的なアイコン画面）より圧倒的に高速で自動化に向くため、エンジニアの主戦場となる。
- **コンパイル（Compile）とバイナリ（Binary）**:
  人間が書いたC言語のソースコード（`.c`）は、そのままではCPUには読めない。コンパイラ（`gcc`）を使って、CPUが直接実行できる「0と1の機械語ファイル（バイナリ）」に翻訳する作業のこと。
- **フォーマット指定子（Format Specifier）**:
  `%s` や `%d` のように、`printf` の中で「ここにどんな型のデータを埋め込むか」を指定する記号のこと。
- **エスケープシーケンス（Escape Sequence）**:
  `\n`（改行）や `\t`（タブ空白）のように、通常の文字入力では打てない特殊な操作を表現する文字列のこと。

## 3. ボス戦ミッション（実装仕様）

このディレクトリにある `Floor_01_Gate/main.c` を開き、ステータス画面を表示するコードを完成させよ。

### 要求される出力フォーマット（寸分の狂いも許されない6行）
実行したとき、画面に以下の通り完全一致で出力されなければならない。

```text
==================================================
  [AINCRAD SYSTEM] : STATUS WINDOW
==================================================
PLAYER : KIRITO
LEVEL  : 0001
HP     : 0250 / 0250
STORAGE: 42.5% USED
==================================================
```

### ステップ・バイ・ステップ実装手引き（写経して感覚を掴もう）

`SAO_PRINT_HEADER` と `SAO_PRINT_FOOTER` の間に、以下の手順で4行の `printf` を書き加えていこう：

1. **1行目（プレイヤー名）**:
   `player_name`（文字列）を `%s` で埋め込む。
   ```c
   printf("PLAYER : %s\n", player_name);
   ```
2. **2行目（レベル）**:
   `level`（整数）を `%04d` で4桁ゼロ埋めして表示する。
   ```c
   printf("LEVEL  : %04d\n", level);
   ```
3. **3行目（HP表示）**:
   `hp_current` と `hp_max` の2つを、スラッシュ `/` で挟んで `%04d` で表示する。
   ```c
   printf("HP     : %04d / %04d\n", hp_current, hp_max);
   ```
4. **4行目（ストレージ使用率）**:
   `storage_used`（小数）を `%.1f` で小数第1位まで表示し、末尾に `%% USED` を付ける。
   ```c
   printf("STORAGE: %.1f%% USED\n", storage_used);
   ```
5. **最後の仕上げ**:
   一番下の `return 1;`（失敗を意味するコード）を、`return 0;`（正常終了）に変更する！
