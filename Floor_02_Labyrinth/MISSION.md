## 🎴 コマンドライン引数と条件分岐の基本パターン（Pattern Example）

この第2層で君が身につけるべき武器は、**「外部からの入力に応じた条件分岐（スイッチ）」** だ。

```c
/* 基本パターン1：引数の数をチェックして守りを固める（早期リターン） */
if (argc < 2) {
    printf("[ERROR] 引数が足りません\n");
    return 1; // 異常終了コードを返して即座に脱出！
}

/* 基本パターン2：文字列が一致しているか調べる */
if (strcmp(argv[1], "-h") == 0) {
    printf("ヘルプを表示します\n");
    return 0; // 成功終了コードを返して完了！
}
```

## 🔍 【まずはここから】いま画面に開いている `main.c` の1行ずつ完全解体新書

エディタで `Floor_02_Labyrinth/main.c` を開くと、第1層とは少し違う新しい呪文が登場している。
上から1行ずつ解体しよう。

```c
1: #include <stdio.h>
2: #include <string.h>
3: 
4: int main(int argc, char *argv[]) {
5:     (void)argc;
6:     (void)argv;
...
```

### 1行目 & 2行目: `#include <stdio.h>` と `#include <string.h>`
- `<stdio.h>`: `printf` を使うための画面表示の道具箱。
- `<string.h>`: 文字列を比較する `strcmp`（ストリング・コンペア）関数が入った文字列操作の道具箱。

### 4行目: `int main(int argc, char *argv[]) {`
- **第1層との決定的な違い**:
  第1層では `main(void)`（引数なし）だったが、ここではカッコの中に **`int argc, char *argv[]`** という2つの変数が登場している！
  - **`argc` (Argument Count / 引数の個数)**:
    ターミナルで実行した時に、いくつの単語が打ち込まれたかを数える整数値（`int`）。
  - **`argv` (Argument Vector / 引数の配列)**:
    打ち込まれた単語たちが順番に入っている文字列のロッカー（配列）。
    - `argv[0]`: 実行したプログラム名自身（例: `"./floor_runner"`）
    - `argv[1]`: 1つ目のオプション（例: `"-h"` や `"stat"` や `"memo"`）
    - `argv[2]`: 2つ目の単語（例: `"Hello"`）

### 5〜6行目: `(void)argc;` と `(void)argv;` の正体
- 第1層と同じく、**「未完成コード用の警告消しのお守り」** だ！
- `argc` や `argv` を使ったコードを自分で書き始めたら、この2行は消去してしまって構わない。

## ⚠️ 初心者が絶対にハマる2大トラップ

### トラップ1: 文字列を `==` で比較してはいけない！
PythonやJavaScriptと違い、C言語で `argv[1] == "-h"` と書いても**絶対に正しく動きません**。
C言語の `==` は、文字列の「中身」ではなく「メモリの住所（アドレス）」を比較してしまうからです。

必ず `<string.h>` の **`strcmp`** を使いましょう：
```c
if (strcmp(argv[1], "-h") == 0) { // 中身が完全一致なら 0 が返る！
    // 一致した時の処理
}
```

### トラップ2: いきなり `argv[1]` を触るとクラッシュする！
引数を何も渡さずに `./floor_runner` とだけ実行した場合、`argv[1]` というロッカーは**存在しません**。
存在しないロッカーを開けようとすると、OSが怒ってプログラムを強制終了（セグフォ）させます。
だからこそ、**一番最初に `argc < 2`（単語が1個以下）かどうかをチェックするガード（早期リターン）** が絶対に必要なのです！

## 🎯 ボス戦クリア目標（実装手順）

エディタで `Floor_02_Labyrinth/main.c` を開き、以下の5つのルールに従ってコマンドライン引数を解析するルーターを完成させよ！

### 【写経して感覚を掴もう】実装のステップ・バイ・ステップ

`main.c` の中身を、以下の手順で上から順番に書いていこう：

```c
#include <stdio.h>
#include <string.h>

int main(int argc, char *argv[]) {
    /* 1. ガード節：引数が存在しない場合（プログラム名しか渡されなかった時） */
    if (argc < 2) {
        printf("[ERROR] NO COMMAND SPECIFIED\n");
        return 1; // エラー終了コード 1 で即座にリターン！
    }

    /* 2. -h オプション（ヘルプ） */
    if (strcmp(argv[1], "-h") == 0) {
        printf("USAGE: gear <stat|memo|clean> [options]\n");
        return 0; // 成功コード 0 で終了
    }

    /* 3. -v オプション（バージョン） */
    if (strcmp(argv[1], "-v") == 0) {
        printf("GEAR VERSION 1.0.0-aincrad\n");
        return 0;
    }

    /* 4. memo コマンド（メモ内容の出力） */
    if (strcmp(argv[1], "memo") == 0) {
        // もし "memo" の後ろに単語が何もない場合 (argc が 2)
        if (argc == 2) {
            printf("[ERROR] EMPTY MEMO\n");
            return 1;
        }
        
        // "memo" の後ろに単語がある場合 (argc >= 3)
        printf("MEMO:");
        for (int i = 2; i < argc; i++) {
            printf(" %s", argv[i]); // スペースを空けて単語を順に出力
        }
        printf("\n"); // 最後に改行
        return 0;
    }

    /* 5. 上記のいずれにも当てはまらない未知のコマンド */
    printf("[ERROR] UNKNOWN COMMAND: %s\n", argv[1]);
    return 1;
}
```
