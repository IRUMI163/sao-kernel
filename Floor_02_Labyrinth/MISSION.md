## 1. この階層で学ぶC言語の核心

### ① コマンドライン引数（`int argc, char *argv[]`）
C言語の `main` 関数は、起動時にコマンドラインから渡された引数を受け取ることができます。

```c
int main(int argc, char *argv[]) {
    // argc : 引数の個数 (Argument Count)
    // argv : 引数文字列の配列 (Argument Vector)
}
```

- **`argc` (Argument Count)**: プログラム名自体を含む引数の総数（整数値）です。
  - 例: `./floor_runner -h` と実行した場合、`argc` は `2` になります。
- **`argv` (Argument Vector)**: 各引数文字列へのポインタ配列です。
  - `argv[0]` : 実行されたプログラムのパス（例: `"./floor_runner"`）
  - `argv[1]` : 第1引数（例: `"-h"`）
  - `argv[2]` : 第2引数（例: `"memo"`）

> ⚠️ **重要**: `argv[argc]` は常に `NULL` です。存在しない `argv[1]` にアクセスしようとするとセグメンテーション違反（クラッシュ）の原因になります。必ず事前に `argc` の値をチェックしてください。

---

### ② 文字列の等価比較（`strcmp` 関数と `<string.h>`）
C言語では、`argv[1] == "-h"` のように `==` 演算子で文字列の内容同士を直接比較することはできません（アドレスの比較になってしまいます）。
文字列の内容が一致しているかを調べるには、`<string.h>` ヘッダをインクルードし、`strcmp` 関数（String Compare）を使用します。

```c
#include <string.h>

if (strcmp(argv[1], "-h") == 0) {
    // argv[1] と "-h" が完全に一致する場合（返り値が 0）
}
```

| 比較結果 | `strcmp(s1, s2)` の返り値 | 意味 |
| :--- | :--- | :--- |
| `s1` と `s2` が完全一致 | `0` | 両方の文字列が等しい |
| `s1` が `s2` より辞書順で前 | 負の値（`< 0`） | `s1` の方が小さい |
| `s1` が `s2` より辞書順で後 | 正の値（`> 0`） | `s1` の方が大きい |

---

### ③ 条件分岐（`if-else`）と 早期リターン（Early Return）
プログラムのガード節として「異常な入力や特定の操作」を関数の冒頭で検知し、すぐに処理を終了して抜け出す手法を**早期リターン（Early Return）**と呼びます。

```c
// 1. 引数が存在しない場合のガード（早期リターン）
if (argc < 2) {
    printf("[ERROR] NO COMMAND SPECIFIED\n");
    return 1; // エラー終了
}

// 2. 引数に応じた分岐処理
if (strcmp(argv[1], "-h") == 0) {
    printf("USAGE: ...\n");
    return 0; // 成功終了
}
```

ネスト（深くなる条件分岐）を避け、コードの可読性と保守性を劇的に向上させるプロの必須テクニックです。

---

### ④ 反復処理（`for` ループ）による可変長引数の連結
可変個の引数を順番に処理したい場合は `for` ループを使用します。

```c
for (int i = 2; i < argc; i++) {
    printf("%s", argv[i]);
    if (i < argc - 1) {
        printf(" "); // 最後の要素以外はスペースを入れる
    }
}
printf("\n");
```

## 2. 現場で飛び交う業界用語辞典

- **パース（引数解析 / Argument Parsing）**:
  ユーザーがコマンドラインに入力した生の文字列群（`argv`）を解析し、プログラムが理解できる命令やオプション構造体に変換する処理のこと。
- **早期リターン（Early Return）**:
  関数の処理冒頭でエラーや特殊条件をチェックし、条件に該当した時点で即座に `return` して関数を抜ける実装パターン。ネストが浅くなり可読性が上がる。
- **エッジケース（Edge Case）**:
  引数が0個、空文字列、境界値、予期せぬ入力など、通常の操作手順から外れた極端または特殊な状況のこと。堅牢なソフトウェア開発ではエッジケースのハンドリングが不可欠。

## 3. ボス戦ミッション（実装仕様）

この階層の `main.c` を編集し、将来の万能CLIツール `gear` のコマンドライン引数解析（パース）エンジンを作成せよ。

### コマンドライン引数と出力の要求仕様

プログラム実行時の第1引数（`argv[1]`）の内容に応じて、以下の通り分岐・出力・終了コード制御を行わなければならない。

#### 1. 引数なし（`argc < 2`）
- **標準出力**: `[ERROR] NO COMMAND SPECIFIED`
- **終了コード**: `1`

#### 2. ヘルプオプション（`./floor_runner -h`）
- **条件**: `strcmp(argv[1], "-h") == 0`
- **標準出力**: `USAGE: gear <stat|memo|clean> [options]`
- **終了コード**: `0`

#### 3. バージョン表示（`./floor_runner -v`）
- **条件**: `strcmp(argv[1], "-v") == 0`
- **標準出力**: `GEAR VERSION 1.0.0-aincrad`
- **終了コード**: `0`

#### 4. メモ記録コマンド（`./floor_runner memo <単語1> <単語2> ...`）
- **条件**: `strcmp(argv[1], "memo") == 0`
- **引数ありの場合（`argc >= 3`）**:
  - 第3引数以降（`argv[2]`, `argv[3]`, ...）を半角スペース1つで連結し、冒頭に `MEMO: ` を付けて出力する。
  - 例: `./floor_runner memo hello world sword art`
  - 出力: `MEMO: hello world sword art`
  - **終了コード**: `0`
- **引数なしの場合（`argc == 2`、つまり `memo` の後ろに単語がない場合）**:
  - **標準出力**: `[ERROR] EMPTY MEMO`
  - **終了コード**: `1`

#### 5. 未知のコマンド（それ以外の全ての引数）
- **標準出力**: `[ERROR] UNKNOWN COMMAND: <argv[1]>`
  - 例: `./floor_runner invalid` ➔ `[ERROR] UNKNOWN COMMAND: invalid`
- **終了コード**: `1`
