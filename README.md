## ⚔️ プロジェクト概要

『**SAO: Kernel**』は、C言語および低レイヤのシステムプログラミング基礎をハンズオン形式でマスターするための超実践型学習コンテンツです。

受講者は各階層（Floor 01 〜 Floor 10）に用意された「ミッション（`MISSION.md`）」を読み、未完成のソースコードを実装・デバッグしながら階層を攻略していきます。各階層で作成したモジュールは、最終的に万能CLIツール『**`gear`**』へと統合されます。

### 📊 学マス式 3大ステータス評価体系

本教材では、学園アイドルマスター（学マス）の評価システムに着想を得た**3大ステータス指標**によって、エンジニアとしての基礎能力を総合的に育成・評価します。

```
       [ Logic (論理・構文) ]
                /\
               /  \
              /    \
             /  SAO \
            / Kernel \
           /__________\
[ Memory (メモリ) ]  [ Audit (監査・堅牢性) ]
```

| ステータス | 意味・育成要素 | 本教材における具体例 |
| :--- | :--- | :--- |
| **Logic (ロジック)** | C言語の基本文法、制御フロー、アルゴリズムの正確な記述力 | `if-else`, `for/while`, `argc/argv` のコマンドライン引数解析, 早期リターン |
| **Memory (メモリー)** | メモリ構造の理解、ポインタ操作、領域の安全な確保と解放 | ポインタ `*`/`&`, `malloc/free`, メモリリーク防止, バッファオーバーフロー防止 |
| **Audit (オーディット)** | エラーハンドリング、防御的プログラミング、バグ監査能力 | `errno`, `perror`, `stderr` への出力, `NULL` ガード, AIを活用した脆弱性・バグ監査 |

## 🛠️ 完全初心者向け環境構築マニュアル

開発環境として **Linux（Ubuntu）** または **Mac (macOS)** を使用します。Windows環境の方は WSL2（Windows Subsystem for Linux）を利用して Ubuntu を構築します。

### 🪟 Windowsユーザー向け手順

#### Step 1: WSL2 (Ubuntu) のインストール
1. スタートメニューを右クリックし、「**PowerShell**（または ターミナル）」を**管理者として実行**します。
2. 以下のコマンドを実行します。
   ```powershell
   wsl --install
   ```
3. 処理が完了したら、**PCを再起動**します。
4. 再起動後、自動的に Ubuntu の初期設定画面（ユーザー名とパスワードの設定）が立ち上がります。画面の指示に従って任意のユーザー名とパスワードを設定してください。

#### Step 2: 必要な開発ツールのインストール
1. Ubuntu のターミナル（黒い画面）を開きます。
2. 以下のコマンドを実行して、C言語コンパイラ（`gcc`）やビルドツール（`make`）、デバッガ（`gdb`）、`git` を一括インストールします。
   ```bash
   sudo apt update && sudo apt install -y build-essential git gdb
   ```
   ※ パスワードを求められたら、Step 1で設定したUbuntuのパスワードを入力してください（入力中の文字は画面に表示されません）。

#### Step 3: Antigravity から WSL2 を開く手順
1. エディタ **Antigravity** を起動します。
2. キーボードで `Ctrl + Shift + P` を押し、コマンドパレットを開きます。
3. `WSL: Connect to WSL` (または `WSL: WSLへ接続`) を検索して選択します。
4. Antigravity 内のターミナルを開き（`Ctrl + @` または 上部メニュー `Terminal` ➔ `New Terminal`）、ターミナル種別で `Ubuntu (WSL)` が選択されていることを確認します。

---

### 🍎 Macユーザー向け手順

1. Macの「**ターミナル**」（Terminal.app）を起動します（`Cmd + Space` で SpotLight を開き「ターミナル」と検索）。
2. 以下のコマンドを実行して、Apple Command Line Tools（`gcc` / `make` / `git` 等）をインストールします。
   ```bash
   xcode-select --install
   ```
3. ポップアップダイアログが表示されたら「**インストール**」をクリックし、規約に同意して完了させます。

## 🖥️ Antigravity 推奨4画面レイアウト設定

Antigravity 画面を以下のように4分割・配置設定することで、開発・学習効率が最大化されます。

```
+------------------------+------------------------+------------------------+
| 【左画面】              | 【中央画面】            | 【右画面】              |
|                        |                        |                        |
| MISSION.md             | コードエディタ          | 茅場晶彦 AIチャット     |
| (Markdown Preview)     | (main.c 等)            | (バグ監査・質問相手)   |
|                        |                        |                        |
+------------------------+------------------------+------------------------+
| 【下画面】 ターミナル (Terminal / Bash / WSL)                           |
| $ gcc -std=c11 -Wall -Wextra -Werror -o floor_runner main.c && ./floor_runner|
+--------------------------------------------------------------------------+
```

### レイアウトの役割と設定方法
- **左画面（`MISSION.md` プレビュー）**:
  各階層の `MISSION.md` を開き、画面右上（または `Ctrl + Shift + V`）で Markdown プレビューを表示します。世界観、解説、実装仕様を常に参照しながら実装できます。
- **中央画面（コードエディタ）**:
  実装対象のソースコード（例: `Floor_01_Gate/main.c`）を開いて編集します。
- **右画面（茅場晶彦 AIチャット）**:
  Antigravity の AI エージェントパネルを開き、システムプロンプトに「茅場晶彦」のペルソナを設定、または質問や `[自主練]` でのコード監査・バグ発見の相談相手として活用します。
- **下画面（ターミナル）**:
  コンパイルコマンドの実行、デバッグ、ボス戦スクリプト（`./test.sh`）の起動を行います。

## 🏰 各階層の進め方 (学習サイクル)

各フロア（Floor 01 〜 Floor 10）の攻略は、以下の**4ステップ**のサイクルで進めます。

```
[① セレクト] ➔ [② レッスン] ➔ [③ 自主練 (AI監査)] ➔ [④ ボス戦 (テスト)]
```

1. **① セレクト (Select)**
   - ターミナルで攻略する階層のディレクトリに移動します。
     ```bash
     cd Floor_01_Gate
     ```
2. **② レッスン (Lesson)**
   - `MISSION.md` をプレビューで熟読します。茅場晶彦からのシステム通達、C言語の文法解説、業界用語辞典、そしてボス戦の仕様を確認します。
3. **③ `[自主練]` (AIバグ監査 / Practice)**
   - スケルトンコードの `/* TODO */` を実装します。
   - 実装したコードを右画面の AIチャットに見せ、**「このコードにメモリリークや未定義動作、バグは潜んでいないか？」** とバグ監査（Audit）を依頼してレビュー・自己改善を行います。
4. **④ ボス戦 (Boss Battle)**
   - ターミナルで自動採点スクリプトを実行し、テストを通過できるか挑戦します。
     ```bash
     ./test.sh
     ```
   - 画面に緑色で **`【判定】 CLEARED!`** と表示されればその階層は突破です！

## 📜 コマンドチートシート

| 操作・目的 | 実行コマンド | 説明 |
| :--- | :--- | :--- |
| **階層へ移動** | `cd Floor_01_Gate` | 指定された階層のフォルダへ移動 |
| **親階層へ戻る** | `cd ..` | ひとつ上のフォルダ（ルート）へ戻る |
| **手動コンパイル & 実行** | `gcc -std=c11 -Wall -Wextra -Werror -o floor_runner main.c && ./floor_runner` | 警告をエラー扱い（`-Werror`）にして厳格にコンパイル・実行 |
| **ボス戦（テスト実行）** | `./test.sh` | 階層クリア条件を満たしているか自動判定 |
| **全体の進行状況確認** | `make status` (または `make`) | 現在クリア済みの階層一覧と進行状況を表示 |
| **模範解答のテスト実行** *(講師用/緊急時)* | `./test.sh --solution` | `.solution/` 配下の模範解答コードでテストを実行 |
| **全階層模範解答の一括テスト** *(講師用/緊急時)* | `make test-solutions` | ルート階層から全10フロアの模範解答を一括テスト |
